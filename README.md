# 新品開發策略工作室

一站式新品開發策略分析工具：填一次產品基本資料，四個分頁分別產出**產品五層次分析**（運用行銷學經典的「產品五層次」理論框架：核心利益／基本產品／期望產品／附加產品／潛在產品）、**SWOT 分析**、**定價策略建議**、**競品比較**。

## 特色

- ⚙️ 免 API 金鑰即可使用（規則式引擎依產品類別關鍵字自動分類、套用對應模板，同一組輸入必定產出同樣結果）
- 🤖 選用串接 Claude／OpenAI／Gemini／OpenRouter（BYOK，自備金鑰）取得更貼近產品情境的 AI 優化內容，AI 回傳缺漏的欄位會自動退回規則式版本補上（逐欄位 fallback，非全有全無）
- 💰 定價策略建議：填入成本與市場參考價可算出建議價格區間（前端公式計算，不採信 AI 回傳的數字）
- ⚔️ 競品比較：直接用你填寫的競品資料組成比較表，不虛構競品資訊
- 📄 匯出完整策略報告（TXT／PDF），整合目前已產生的所有分頁內容
- 📱 響應式設計，手機／平板／桌面皆可使用

## 使用方式

直接開啟 `index.html`，或用任意靜態伺服器託管本資料夾即可，無需安裝、無需建置步驟。

```bash
python -m http.server 8803 --directory .
```
