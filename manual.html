操作手冊

一站式新品開發策略分析：產品五層次分析・SWOT 分析・定價策略建議・競品比較。

操作步驟

  1. 上方「產品基本資料」填產品名稱、產品類別、目標客群、市場痛點或需求；也可以先點快速範例按鈕，套用一組虛構產品範例再自行修改
  2. 四個分頁（🎯五層次分析／📊SWOT分析／💰定價策略建議／⚔️競品比較）分別按各自的「產生」按鈕，沒有 AI 金鑰也能用規則式引擎產生完整內容（依你填的產品類別與痛點關鍵字自動分類、套用對應模板）
  3. 想要更貼近你產品情境的內容，可展開「AI 連線設定」，填入你自己的 API 金鑰，之後每個分頁按「產生」都會自動改用 AI（AI 回傳的內容若有欄位缺漏，會自動用規則式版本補上該欄位，不會整份失敗）
  4. 「定價策略建議」分頁：填入預估成本與市場參考價（皆選填）可算出建議價格區間；留空則只提供策略方向建議
  5. 「競品比較」分頁：填入 1-3 個競品的名稱、價格區間、主打特色、已知弱點（僅名稱必填），系統會整理成比較表並提供差異化建議與風險提醒
  6. 最下方「匯出完整策略報告」可以把目前已產生的分頁內容整合匯出成 TXT 或 PDF，尚未產生的分頁會標註「尚未產生」
四個分頁共用同一組「產品基本資料」與「AI 連線設定」，不需要每個分頁分別填寫。

五組快速範例

「產品基本資料」下方有 5 個快速範例按鈕，涵蓋健康科技、餐飲食品、軟體服務、生活家電、教育內容五種不同類型的虛構產品，方便快速上手，也能觀察不同產業類別會怎麼影響規則式引擎產出的內容措辭。點下去會直接覆蓋目前表單內容（含競品資料與定價欄位）。

關於「規則式」與「AI優化」

每個分頁都有兩種產生方式，由是否填 API 金鑰自動切換：

  • 規則式引擎（免 AI）：依你填的「產品類別」「痛點/需求」關鍵字，自動分類到六種產業桶之一（健康科技／餐飲食品／軟體服務／生活家電／教育內容／一般消費），套用對應的內建模板並帶入你的產品名稱、目標客群、痛點文字。同一組輸入永遠產生同樣的結果。
  • AI 優化（選用，BYOK）：把產品資料送給你選擇的語言模型，請它針對這個產品直接撰寫分析內容。AI 回傳的每個欄位會分別檢查，缺漏或格式不對的欄位會自動改用規則式版本補上（畫面上會標示「AI＋規則式混合版本」並列出哪些項目是補上的），不會因為某個欄位出問題就整份放棄。

加入主畫面（可選）

頁尾按「📲 加入主畫面」，可以把這個工具像 App 一樣安裝到手機或電腦桌面，之後不用開瀏覽器輸網址就能直接點圖示開啟。

安裝與否不影響任何功能，純粹是操作方便性；不安裝、直接用瀏覽器開網址一樣可以完整使用。
